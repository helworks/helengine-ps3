Core intended change (adapt to exact source style/includes):

```cpp
CFPParser::CFPParser() : CParser() { m_pInstructions = NULL; }
// At Parse entry, before constructing the input stream:
if (str == NULL) {
    fprintf(stderr, "cgcomp: fragment assembly source is null.\n");
    exit(EXIT_FAILURE);
}
size_t capacity = 1;
for (const char* cursor = str; *cursor != '\0'; ++cursor) {
    if (*cursor == '\n') {
        if (capacity == static_cast<size_t>(INT_MAX)) {
            fprintf(stderr, "cgcomp: fragment assembly has too many lines.\n");
            exit(EXIT_FAILURE);
        }
        ++capacity;
    }
}
delete[] m_pInstructions;
m_pInstructions = NULL;
m_nInstructions = 0;
m_pInstructions = new nvfx_insn[capacity];
// Immediately before the existing insn = &m_pInstructions[m_nInstructions]:
if (static_cast<size_t>(m_nInstructions) >= capacity) {
    fprintf(stderr, "cgcomp: fragment parser instruction capacity exceeded.\n");
    exit(EXIT_FAILURE);
}
```

Include the standard headers needed for INT_MAX and exit; use the descriptive diagnostics above. Existing parser is a command-line tool; preserve visible process failure rather than returning an ignored Parse status. No patch to generated shader data. Do not alter MAX_NV_FRAGMENT_PROGRAM_INSTRUCTIONS globally or the vertex parser. The regression binary has expected magic 0x4650 at offset 0, U16 big-endian instruction count at offset 10 and U32 big-endian microcode offset at offset 20 (verified against Ps3RsxProgramReader).
