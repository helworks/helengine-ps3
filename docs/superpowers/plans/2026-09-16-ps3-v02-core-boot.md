# PS3 v0.2 Generated-Core Boot Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a PS3 executable containing the generated Core C++ that completes a full Core lifecycle (construct, initialize, update/draw/frame-boundary cycles, dispose, exit zero) with the v0.1 cube still drawing underneath.

**Architecture:** Two halves meeting at a generated-core root directory. A builder assembly in this repository declares the `ps3` platform and its codegen profile, and invokes the existing containerized native build. The native host gains four minimal Core adapters and a runtime host that owns the Core lifetime behind the existing boot host. The Core path is selected by an explicit build mode; with it off the executable is byte-for-byte the v0.1 behaviour.

**Tech Stack:** C# (net9.0) against `helengine.baseplatform`, the pinned `helengine-ps3-sdk` Docker image (ppu-gcc 13.2.0, PSL1GHT), GNU Make, PowerShell, RPCS3 for runtime evidence.

**Spec:** `../specs/2026-09-16-ps3-v02-core-boot-design.md`

## Global Constraints

Copied from the spec; every task inherits these.

- The milestone is the Core lifecycle gate only. Authored scene loading, cooked content, materials, shaders, textures, physics, audio, real input, SPU work and hardware validation are out of scope.
- Codegen endianness is **big-endian**. The Cell PPU is big-endian; Dreamcast's little-endian declaration must not be copied.
- Exceptions and RTTI are **enabled**, overriding the `stl-lite` profile default of disabled.
- Pointer size is **measured inside the SDK image**, never assumed.
- The demodisc build entry carries **no prebuild scene generation**. A prebuild step of that kind previously destroyed authored scenes on PS2 and PSP.
- Generated output is never edited after generation. A wrong output is fixed in the generator or the codegen profile.
- Native types stay under `src/platform/ps3/`, namespace `helengine::ps3`, one class per file, with substantive documentation comments on every class, function and field.
- Build artifacts, logs and generated trees live under `C:\dev\helworks\builds\helengine-ps3\`, never in the worktree and never in `%TEMP%`.
- Commit only the named files of a completed task. Never `git add .`. Do not push.
- Work on branch `feature/ps3-v02-core-boot`.

## Task 1: Measure the toolchain facts the codegen profile depends on

The codegen profile must state the PPU pointer size, and the spec commits to enabling exceptions. Both are measured before any profile is written, because guessing either produces a generated tree that miscompiles in ways that look like unrelated bugs.

**Files:**
- Create: `scripts/probe-core-abi.ps1`
- Create: `docs/CoreAbiProbe.md`

**Interfaces:**
- Consumes: the locked SDK image id from `toolchain-lock.json` `ResolvedImage.ImageId`.
- Produces: `docs/CoreAbiProbe.md` recording `PointerSizeBytes`, `LongSizeBytes`, `Endianness`, `ExceptionsWork`, `RttiWork`. Task 2 copies `PointerSizeBytes` into the codegen profile verbatim.

- [ ] **Step 1: Write the probe script**

Create `scripts/probe-core-abi.ps1`. It reads the locked image id, writes a small C++ file into a fresh directory under `C:\dev\helworks\builds\helengine-ps3\core-abi-<utc>\`, compiles and runs nothing on the host, and instead compiles inside the image and reports sizes via a compile-time static assertion sweep plus a runtime program whose output is captured only in the emulator. Since the probe cannot execute PPU code on the host, sizes are extracted at compile time:

```powershell
[CmdletBinding()]
param(
    [string]$ExternalRoot = 'C:\dev\helworks\builds\helengine-ps3'
)
$ErrorActionPreference = 'Stop'
Set-StrictMode -Version Latest

$repoRoot = [IO.Path]::GetFullPath((Join-Path $PSScriptRoot '..'))
$lock = Get-Content -LiteralPath (Join-Path $repoRoot 'toolchain-lock.json') -Raw -Encoding UTF8 | ConvertFrom-Json
$imageId = [string]$lock.ResolvedImage.ImageId
if ([string]::IsNullOrWhiteSpace($imageId)) { throw 'toolchain-lock.json has no ResolvedImage.ImageId. Run scripts/prepare_toolchain.ps1.' }

$stamp = (Get-Date).ToUniversalTime().ToString('yyyyMMdd-HHmmss')
$probeRoot = Join-Path ([IO.Path]::GetFullPath($ExternalRoot)) "core-abi-$stamp"
New-Item -ItemType Directory -Path $probeRoot | Out-Null

Set-Content -LiteralPath (Join-Path $probeRoot 'abi.cpp') -Encoding Ascii -Value @(
    '#include <cstdio>',
    '#include <stdexcept>',
    '#include <typeinfo>',
    'struct Base { virtual ~Base() {} };',
    'struct Derived : Base {};',
    'template <int N> struct Report;',
    'int main() {',
    '    std::printf("PointerSizeBytes=%d\n", (int)sizeof(void*));',
    '    std::printf("LongSizeBytes=%d\n", (int)sizeof(long));',
    '    unsigned int probe = 1u;',
    '    std::printf("Endianness=%s\n", (*(unsigned char*)&probe) == 1u ? "little" : "big");',
    '    int caught = 0;',
    '    try { throw std::runtime_error("probe"); } catch (const std::exception&) { caught = 1; }',
    '    std::printf("ExceptionsWork=%d\n", caught);',
    '    Derived derived; Base* base = &derived;',
    '    std::printf("RttiWork=%d\n", dynamic_cast<Derived*>(base) != nullptr ? 1 : 0);',
    '    return 0;',
    '}'
)
Set-Content -LiteralPath (Join-Path $probeRoot 'sizes.cpp') -Encoding Ascii -Value @(
    'template <int Size> struct PointerSizeIs;',
    'template <> struct PointerSizeIs<4> { static const int value = 4; };',
    'template <> struct PointerSizeIs<8> { static const int value = 8; };',
    'static_assert(sizeof(void*) == 4 || sizeof(void*) == 8, "unexpected pointer size");',
    'int pointerSizeMarker = PointerSizeIs<(int)sizeof(void*)>::value;'
)

$script = 'set -e; cd /probe; ppu-g++ -std=c++17 -mcpu=cell -fexceptions -frtti -c sizes.cpp -o sizes.o; ' +
          'ppu-g++ -std=c++17 -mcpu=cell -fexceptions -frtti -I$PSL1GHT/ppu/include abi.cpp -L$PSL1GHT/ppu/lib -lrt -llv2 -o abi.elf; ' +
          'ppu-readelf -h abi.elf; ppu-nm sizes.o | grep pointerSizeMarker; ' +
          'echo "STATIC_POINTER_SIZE=$(ppu-g++ -std=c++17 -mcpu=cell -E -P -x c++ - <<< ' + "'" + 'int x = sizeof(void*);' + "'" + ' >/dev/null && ppu-g++ -std=c++17 -mcpu=cell -dM -E -x c++ /dev/null | grep -E "__SIZEOF_POINTER__|__BYTE_ORDER__|__ORDER_BIG_ENDIAN__")"'

$output = & docker run --rm --network none --mount "type=bind,source=$probeRoot,target=/probe" --entrypoint /bin/bash $imageId -c $script 2>&1 |
    ForEach-Object { if ($_ -is [System.Management.Automation.ErrorRecord]) { [string]$_.Exception.Message } else { [string]$_ } }
if ($LASTEXITCODE -ne 0) { throw "ABI probe failed:`n$($output -join [Environment]::NewLine)" }
$output | Set-Content -LiteralPath (Join-Path $probeRoot 'probe.log') -Encoding UTF8
$output | Write-Output
Write-Output "Probe outputs: $probeRoot"
```

```csharp
using System.Diagnostics;
using helengine.baseplatform.Requests;

namespace helengine.ps3.builder;

/// <summary>Runs the pinned PowerShell and Docker native build in an explicit source checkout.</summary>
public sealed class Ps3NativeBuildExecutor : IPs3NativeBuildExecutor {
    /// <summary>Builds a Core-mode executable from the supplied generated Core root.</summary>
    /// <param name="request">Complete platform request.</param>
    /// <param name="generatedCoreRoot">Root of the generated Core C++ tree.</param>
    /// <param name="cancellationToken">Cooperative cancellation token.</param>
    public void Build(PlatformBuildRequest request, string generatedCoreRoot, CancellationToken cancellationToken) {
        if (request == null) {
            throw new ArgumentNullException(nameof(request));
        } else if (string.IsNullOrWhiteSpace(generatedCoreRoot)) {
            throw new ArgumentException("Generated Core root is required.", nameof(generatedCoreRoot));
        }
        cancellationToken.ThrowIfCancellationRequested();

        string repositoryRoot = Environment.GetEnvironmentVariable("HELENGINE_PS3_REPOSITORY_ROOT");
        if (string.IsNullOrWhiteSpace(repositoryRoot)) {
            throw new InvalidOperationException("Set HELENGINE_PS3_REPOSITORY_ROOT to the PlayStation 3 source checkout before invoking the native executor.");
        }
        repositoryRoot = Path.GetFullPath(repositoryRoot);
        string buildScript = Path.Combine(repositoryRoot, "scripts", "build.ps1");
        if (!File.Exists(buildScript)) {
            throw new FileNotFoundException("PlayStation 3 native build script was not found in HELENGINE_PS3_REPOSITORY_ROOT.", buildScript);
        }

        string powershell = Environment.GetEnvironmentVariable("HELENGINE_PS3_POWERSHELL") ?? "powershell";
        string buildId = $"core-{Guid.NewGuid():N}";
        ProcessStartInfo startInfo = new(powershell) {
            WorkingDirectory = repositoryRoot,
            UseShellExecute = false
        };
        startInfo.ArgumentList.Add("-NoProfile");
        startInfo.ArgumentList.Add("-File");
        startInfo.ArgumentList.Add(buildScript);
        startInfo.ArgumentList.Add("-BuildId");
        startInfo.ArgumentList.Add(buildId);
        startInfo.ArgumentList.Add("-Mode");
        startInfo.ArgumentList.Add("Core");
        startInfo.ArgumentList.Add("-OutputRoot");
        startInfo.ArgumentList.Add(request.OutputRoot);
        startInfo.ArgumentList.Add("-GeneratedCoreRoot");
        startInfo.ArgumentList.Add(generatedCoreRoot);

        using Process process = new() { StartInfo = startInfo, EnableRaisingEvents = true };
        if (!process.Start()) {
            throw new InvalidOperationException("Failed to start the PlayStation 3 native build process.");
        }
        try {
            process.WaitForExitAsync(cancellationToken).GetAwaiter().GetResult();
        } catch (OperationCanceledException) {
            try {
                process.Kill(entireProcessTree: true);
            } catch (InvalidOperationException) {
            }
            throw;
        }
        if (process.ExitCode != 0) {
            throw new InvalidOperationException($"PlayStation 3 native build failed with exit code {process.ExitCode}.");
        }

        string buildRoot = Path.Combine(request.OutputRoot, buildId);
        if (!File.Exists(Path.Combine(buildRoot, "helengine_ps3.self")) ||
            !File.Exists(Path.Combine(buildRoot, "build-manifest.json"))) {
            throw new InvalidOperationException($"PlayStation 3 native build completed without a verified output manifest: {buildRoot}");
        }
    }
}
```

The engine range mirrors Dreamcast's deliberately wide window, which is what lets a builder satisfy both an isolated engine build and the shared engine's `1.0.0+<commit>` string.

```csharp
using helengine.baseplatform.Builders;
using helengine.baseplatform.Descriptors;
using helengine.baseplatform.Reporting;
using helengine.baseplatform.Requests;
using helengine.baseplatform.Results;

namespace helengine.ps3.builder;

/// <summary>Publishes the PlayStation 3 platform contract and delegates native execution behind an injectable seam.</summary>
public sealed class Ps3PlatformAssetBuilder : IPlatformAssetBuilder {
    readonly IPs3NativeBuildExecutor NativeBuildExecutor;

    /// <summary>Creates a builder using the production native executor.</summary>
    public Ps3PlatformAssetBuilder()
        : this(new Ps3NativeBuildExecutor()) {
    }

    /// <summary>Creates a builder using a caller-provided native executor.</summary>
    /// <param name="nativeBuildExecutor">Executor used for the native build phase.</param>
    public Ps3PlatformAssetBuilder(IPs3NativeBuildExecutor nativeBuildExecutor) {
        NativeBuildExecutor = nativeBuildExecutor ?? throw new ArgumentNullException(nameof(nativeBuildExecutor));
        Descriptor = new PlatformBuilderDescriptor(
            "helengine.ps3.builder",
            "0.2.0",
            "ps3",
            new EngineCompatibilityRange("0.4.0", "999.0.0"),
            new ManifestCompatibilityRange(1, 1),
            ["ps3"],
            ["ps3"]);
        Definition = Ps3PlatformDefinitionFactory.Create();
    }

    /// <summary>Gets the discovery descriptor for this builder.</summary>
    public PlatformBuilderDescriptor Descriptor { get; }

    /// <summary>Gets the typed editor-facing platform definition.</summary>
    public helengine.baseplatform.Definitions.PlatformDefinition Definition { get; }

    /// <summary>Refuses material cooking, which belongs to the authored scene milestone rather than the boot gate.</summary>
    /// <param name="request">Material request from the build graph.</param>
    /// <returns>Never returns; always throws.</returns>
    /// <exception cref="NotSupportedException">Always thrown, naming the milestone that will implement cooking.</exception>
    public PlatformMaterialCookResult CookMaterial(PlatformMaterialCookRequest request) {
        throw new NotSupportedException("The PlayStation 3 v0.2 boot gate does not cook materials. Material cooking arrives with the authored scene milestone.");
    }

    /// <summary>Regenerated Core is compiled into the native executable; no content is staged in this milestone.</summary>
    /// <param name="request">Resolved graph build request.</param>
    /// <param name="progressReporter">Progress callback.</param>
    /// <param name="diagnosticReporter">Diagnostic callback.</param>
    /// <param name="cancellationToken">Cooperative cancellation token.</param>
    /// <returns>Final scene and loose-asset outcomes.</returns>
    public async Task<PlatformBuildReport> BuildAsync(
        PlatformBuildRequest request,
        IPlatformBuildProgressReporter progressReporter,
        IPlatformBuildDiagnosticReporter diagnosticReporter,
        CancellationToken cancellationToken) {
        if (request == null) {
            throw new ArgumentNullException(nameof(request));
        } else if (progressReporter == null) {
            throw new ArgumentNullException(nameof(progressReporter));
        } else if (diagnosticReporter == null) {
            throw new ArgumentNullException(nameof(diagnosticReporter));
        }

        List<PlatformBuildDiagnostic> diagnostics = [];
        try {
            cancellationToken.ThrowIfCancellationRequested();
            if (!string.Equals(request.Manifest.PlatformName, "ps3", StringComparison.OrdinalIgnoreCase)) {
                throw new InvalidOperationException($"PlayStation 3 builder received manifest for platform '{request.Manifest.PlatformName}'.");
            }
            if (string.IsNullOrWhiteSpace(request.GeneratedCoreCppRootPath)) {
                throw new InvalidOperationException("PlayStation 3 Core build requires GeneratedCoreCppRootPath.");
            }
            Directory.CreateDirectory(request.OutputRoot);
            progressReporter.Report(new PlatformBuildProgressUpdate("Build Native SELF", "ps3", 0, 1, "Preparing the PlayStation 3 native executor."));
            NativeBuildExecutor.Build(request, request.GeneratedCoreCppRootPath, cancellationToken);
            progressReporter.Report(new PlatformBuildProgressUpdate("Build Native SELF", "ps3", 1, 1, "Built the PlayStation 3 native runtime."));
        } catch (OperationCanceledException) {
            throw;
        } catch (Exception exception) {
            PlatformBuildDiagnostic diagnostic = new(
                PlatformBuildDiagnosticSeverity.Error,
                "PS3BUILD_FAILED",
                exception.Message,
                request.Manifest.StartupSceneId,
                string.Empty,
                "ps3-builder");
            diagnostics.Add(diagnostic);
            diagnosticReporter.Report(diagnostic);
        }

        PlatformBuildItemOutcomeKind outcomeKind = diagnostics.Count == 0
            ? PlatformBuildItemOutcomeKind.Succeeded
            : PlatformBuildItemOutcomeKind.Failed;
        return await Task.FromResult(new PlatformBuildReport(
            diagnostics.Count == 0,
            [.. diagnostics],
            request.Manifest.Scenes.Select(scene => new PlatformBuildItemOutcome(scene.SceneId, outcomeKind)).ToArray(),
            request.Manifest.LooseAssets.Select(asset => new PlatformBuildItemOutcome(asset.AssetId, outcomeKind)).ToArray()));
    }
}
```
